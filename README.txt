Party Management Pro

Upload index.html, manifest.json, service-worker.js, icon-192.png and icon-512.png to the same GitHub Pages folder.

Default password for existing/new data: 1234. Change it immediately in Settings.

Passkey requires HTTPS and a supported browser. This is a local device lock; for true multi-device/server security use Firebase Authentication.

Google Drive requires your own OAuth Web Client ID; the placeholder in index.html will not authenticate until configured.
